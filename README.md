# 頭痛ノート

片頭痛と緊張型頭痛の発作、服薬、気圧の変化を記録するスマホ向けWebアプリ（PWA）です。PWAは、ブラウザで開いたページをホーム画面に追加して、アプリのように使える仕組みです。記録はすべて端末のブラウザの中に保存し、外部には送りません。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 「頭痛が始まった」ボタンで記録を始め、「治まった」で終了時刻を記録します。服薬の記録、前後24時間の気圧グラフ、直近30日の頭痛日数と服薬日数も表示します |
| 記録フォーム | 痛みの強さ（0〜10）、場所、痛み方、随伴症状（頭痛と一緒に出る吐き気や光過敏など）、きっかけ、飲んだ薬と効き目、メモを入力します。選んだ症状から、片頭痛と緊張型頭痛のどちらの特徴に近いかを表示します |
| カレンダー | 頭痛のあった日を種類別の色で、服薬した日を「薬」の印で表示します。日付を押すとその日の記録を見られます |
| 分析 | 30日、90日、180日の期間で、頭痛日数、平均の強さと持続時間、きっかけの回数、薬ごとの効き目、頭痛が始まる前に気圧が下がっていた割合を集計します |
| 受診用レポート | 医師に見せるための一覧表を作ります。ブラウザの印刷機能でPDFにも保存できます |
| 設定 | 気圧を取得する地域、薬の一覧、データの書き出しと読み込みを管理します |

直近30日で頭痛薬を飲んだ日が8日に達すると注意を、10日以上になると警告を表示します。国際頭痛分類（ICHD-3）では、トリプタンや複合鎮痛薬を月10日以上、単一の鎮痛薬を月15日以上飲む状態が続くと、薬が原因で頭痛が増える「薬剤の使用過多による頭痛」が疑われるとしています。アプリは複数の薬を合わせた日数で判定し、種類を「予防薬」にした薬は数えません。

## 気圧データ

気象データサービス Open-Meteo（APIキー不要、無料）から地上気圧の1時間ごとの値を取得します。送る情報は、設定で登録した地域の緯度と経度（小数第2位まで）だけです。頭痛を記録した時点の気圧と、その6時間前からの変化量を記録に保存します。今後24時間のうち、6時間で3hPa以上下がる区間があるとホームに注意を表示します。この3hPaはアプリで決めた値で、医学的な基準ではありません。値は `app.js` の `PRESSURE_DROP_WARN` で変えられます。

## PCで動かす

```bash
python -m http.server 8950 --directory headache_app
```

ブラウザで http://localhost:8950 を開きます。

## スマホで使う

スマホのホーム画面に追加するには、HTTPSで配信する必要があります。GitHub Pages、Cloudflare Pages、Netlify などの無料の静的サイト配信に、このフォルダをそのまま置けば動きます。サーバー側の処理はありません。

配信したURLをスマホで開いたあと、iPhoneはSafariの共有ボタンから「ホーム画面に追加」を、AndroidはChromeのメニューから「ホーム画面に追加」を選びます。

## データの保存先

記録はブラウザの localStorage に保存します。次の場合に記録が消えるため、設定画面の「書き出し（JSON）」でときどき保存してください。

- ブラウザの履歴やサイトデータを消したとき
- iPhoneでホーム画面に追加せずSafariで使い、長期間開かなかったとき
- 機種変更したとき（書き出したJSONを新しい端末で読み込めば移せます）

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の枠 |
| app.js | 記録、集計、気圧取得、画面描画のすべての処理 |
| style.css | 見た目（ダークモード、印刷用レイアウトを含む） |
| sw.js | オフラインで開くためのキャッシュ処理（Service Worker） |
| manifest.webmanifest, icon-*.png, icon.svg | ホーム画面に追加したときの名前とアイコン |

## 注意

このアプリは記録用で、診断はしません。いつもと違う激しい頭痛、手足のしびれ、ろれつが回らない、発熱を伴う頭痛などがあるときは、すぐに医療機関を受診してください。
